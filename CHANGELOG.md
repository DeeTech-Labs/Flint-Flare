# Changelog

All notable changes to **Flint Flare** are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Application versions in `CMakeLists.txt` aim to follow
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Changed
- Refresh RU/EN onboarding, build/test/contributor routes, user recovery and extension guides against the implemented shared SDK contract.
- Require SDK development contract `0x20261114` and FLM3 packages with component-local budgets, permissions, capabilities and Lua sections. Pin the validated SDK revision `6e7a853`. See [background services](docs/en/background-services.md).

### Added
- Explicit background service monitoring, execution/autostart permissions and start/stop/pause/resume/revoke actions through the shared Core, with metadata-only diagnostics and a virtual low-energy simulator policy.
- Sensor availability/state catalog, explicitly enabled diagnostic leases, bounded sampling and local simulation controls through the shared SDK Core.
- Confirmed brightness/mute policy settings, localized sensor permission labels and explicit RTC acknowledgement/partial-failure reporting.
- Studio support for prepared FLIM v2 icons, including the image converter in the compiler bundle.
- Device overview actions and session-aware time synchronization and permission feedback.
- Protocol v1 request IDs, atomic device settings, local profiles and settings backup/restore.
- Protocol simulator and Ignite Studio with pixel icon editing, library, favorites and device installation.
- BLE discovery, GATT connection, shared INFO/STATUS/TIME commands and session reconnect.
- System/light/dark themes, larger clock preview and overlay notifications.
- Companion protocol documentation and Bluetooth build dependencies.
- USB Companion notes, clipboard send, focus timer, Linux CPU/RAM metrics and find-watch indicator.
- Local event timeline with JSON export, file live reload and optional system tray mode.

- Qt6 / C++17 / QML application with CMake and Qt Creator support.
- USB device discovery, protocol handshake and capability-based device information.
- Periodic status collection, PC time synchronization and bounded USB diagnostics.
- Manual JSON session export and command-line capture.
- Serial-emulator integration tests for real Qt client behavior and error handling.
- Shared FlinT branding, contributor documentation, issue forms and CODEOWNERS.
- Linux Qt build and test workflow for pull requests and `main`.
- Dark dashboard with reusable QML controls, responsive pages and a shared theme.
- English and Russian JSON language packs split by page, with runtime switching.
- UI, catalog and timezone tests, plus Linux/macOS/Windows build checks.

### Fixed
- Translate shared protocol errors in the selected interface language and preserve background service status messages across language changes.
- Stop diagnostic demand when its page/window becomes inactive or transport disconnects; do not resume session telemetry after reconnect.
- Recheck authoritative settings after a partial mutation failure while retaining the original error; never present failed grant/settings operations as successful.
- Ignore stale permission responses after package selection or connection changes.
- Embed factory packages and examples generated by the pinned SDK in the build directory.
- Prefer the available Windows Python interpreter over the Python 3 App Execution Alias.

- Handle delayed BLE service UUIDs, use a longer scan and select the public Spark address on Linux without CAP_NET_ADMIN.
- Own a Linux BlueZ discovery reference when another Bluetooth client is already scanning.
- Request Linux pairing explicitly before encrypted GATT access.

- Keep the interface stable during background status polling.
- Apply the device timezone when displaying its clock time.
