# Архитектура Flint Flare

Оболочка QML и повторно используемые визуальные компоненты находятся в `qml/`. Иконки, шрифты, шейдеры, локализация и интеграция с системным треем независимы от протокола устройства.

`src/platform_app/` содержит PlatformClient, IgniteHub, Studio, Preview и CompanionService. Они используют типизированные бинарные ID методов и общие кодеки v1, не предоставляя QML старые текстовые команды или слой совместимости.

`src/device/` содержит только повторно используемый аппаратный жизненный цикл Qt Bluetooth/BlueZ. `platform/` — закреплённый подмодуль Flint IgniteSDK: переносимый Core, менеджеры пакетов и ресурсов, Runtime, очередь событий, рендерер, компилятор и контракты. Симулятор исполняет тот же Core в изолированном временном каталоге.

Вкладка «Мои часы» показывает сведения текущей сессии PlatformClient: профиль, сборку, бюджеты памяти, свободное хранилище и активное приложение. Неизвестные значения отображаются как «Нет данных»; при отключении блок сведений, превью и настройки выгружаются. Пустое состояние ведёт к общему экрану подключения, не создавая отдельное соединение. Симулятор явно обозначается как виртуальное устройство. Управление временем и восстановлением вынесено в раскрываемый компонент WatchControls; смещение UTC вводится пользователем, восстановление требует подтверждения.

[Общая спецификация](../../platform/README.md) определяет форматы, согласия, транзакции, доверие и явно неподдерживаемые возможности.


Companion по потребности использует [общий контракт SDK](../../platform/docs/ru/COMPANION.md). Ignite Hub не включает сбор данных. Без локального согласия, активной потребности, binding и поддержки источника sampling не запускается; permissions polling отсутствует. События не завершают pending request и не сбрасывают timeout. Поставщик CPU/RAM пока поддерживается только на Linux. `FLINT_PLATFORM_DIR` — явный development override; обычная сборка использует закреплённый `platform/`.

PlatformClient держит отдельный bounded slot и timeout для продолжаемого `install_commit`; обычные команды и Companion samples обслуживаются, пока SDK проверяет пакет. Очередь ограничена 64 запросами, повторные samples объединяются, управление имеет приоритет перед ожидающими samples. BLE передаёт кадры последовательно и сообщает готовность следующего кадра; callbacks старого поколения игнорируются.

При поддержке `CapSessionClose` закрытие USB отправляет `session_close` и асинхронно ждёт ACK до 100 мс. Поздние ответы установки не завершают закрытие. Без подтверждения результат установки проверяется по каталогу после reconnect. Исчезновение поставщика освобождает binding по lease SDK.

Политика Bluetooth в настройках часов доступна только при `CapBlePolicy`. Flare читает её при handshake, показывает подтверждённое значение и блокирует повторную запись до ответа. Ошибка не меняет отображаемую политику. После отключения радио требуется USB для включения. Companion consent и Ignite Hub не меняют эту настройку.

Disconnect отменяет продолжаемую проверку установки только до начала публикации. После этой границы SDK завершает durable publication и отбрасывает ответ старой сессии. После reconnect Hub перечитывает каталог; потеря соединения/ACK не доказывает отмену установки. Wire method/request ID и timeout 45 секунд не изменяются.
